# M7 — Stray-style HUDs and visual refinement / 0.8.0-dev

## Implemented in this batch

### Nametags refinement

Player plates now preserve styled display-name components rather than flattening names into a plain health/distance string. Rounded fill, subtle configurable border, muted distance, optional separate health row, opacity and distance scaling follow Stray's visual structure. Distance scale is clamp(24/(12+distance), 0.52, 1.35), multiplied by user scale. Distance is hidden for the optional self tag. Existing eligibility, NPC filter, line-of-sight cache, F1 and pooled-state replacement guards remain.

No remote developer/shop badge system, special font, non-player tags or source custom cosmetics are implied. The health row is a solyanka extension. Existing saved settings remain, with defaults for new controls.

### Block Outline refinement

The same current-frame voxel contour/fill now has an optional three-layer alpha-blended halo, widest/faintest to narrowest/stronger, plus the crisp contour. Glow radius (1–8) and strength (0.1–1) are sliders; disable Glow for old behavior. At most 1024 shape edges, each with three halo segments plus core; at most 128 fill boxes.

**This is a geometry approximation, not the upstream entity-outline/framebuffer blur shader.** It does not establish shader-pack/GPU compatibility or source glow parity. The null-selection callback remains explicitly nullable; no-target safety is checked against compiled bytecode.

### Scoreboard (`hud.scoreboard`)

Rounded themed panel replaces the vanilla SCOREBOARD layer only while enabled. Team-color sidebar objective takes precedence, falling back to general SIDEBAR. Uses the 26.2 Optional<TeamColor> / TeamColor.displaySlot API, not old ChatFormatting mapping. Hidden entries excluded, up to 15 rows, descending scores with deterministic owner tie-break. Team prefixes/suffixes and objective/entry number formats retained.

Configurable scores/header/shadow, panel/accent/border colors, max width 100–400, HUD visibility and x/y/scale. Long rows/title are clipped under the transformed GUI pose; score/name regions do not overlap. No objective/rows produces no fabricated HUD. Disabling the module restores vanilla. HUD visibility off hides the sidebar while its module remains enabled.

`/solyanka gui` has 18 entries. The scoreboard uses a labelled, representative five-row editor sample and stored max width; it does not enable the master module. Runtime height/width follow actual rows and capped text width, so editor bounds are representative rather than a live-server layout promise.

### Themed Chat (`hud.themed_chat`)

Source-inspired rounded pane behind native messages plus matching input background. Pane follows vanilla chat scale, spacing, scroll position, focused page height and 200-tick line lifetime. Wide line fills are suppressed only inside the wrapped native draw scope. Thin scrollbar fills and message-security tag/icon handlers remain native. Scope restoration uses try/finally and a thread-local flag.

Native text submit, chat content, signatures, links/clicks/hover geometry, command suggestions, history and input geometry are unchanged. Existing NoFrills copy/history features continue to use the same geometry. The input fill hook changes only the original fill rectangle. No rewriting, network calls, click automation, source tag suppression, frost blur, custom fonts or slide/bump animation.

Both new master switches default off. Settings use embedded instant-save panels, sliders and shared palettes. Source custom theme/font/blur systems are not part of this adaptation.

## Validation boundary

Clean build, pure/config/layout tests and static descriptor/callsite checks only. No Minecraft launch, Mixin application, game-server, Sodium, Iris or GPU rendering test here.

Manual acceptance:
1. Names: compare near/far and rank-colored players, self in third person, health on/off, rounded border/opacity/scale toggles. Check restored vanilla tags after disable and no duplicated labels.
2. Block: compare halo off/on across slabs/stairs/full cubes, range of widths/radii/strengths, through-walls setting and no target. Verify stable alpha blending and no GPU artifacts.
3. Scoreboard: general vs team-colored objective, hidden entries, blank/formatted score fields, long team prefixes and 15+ rows. Move/scale, reopen/restart; check vanilla restoration and F1.
4. Chat: focused/unfocused, expiry, scaled/expanded/scrolling chat, wrapping, links and item hover, copy shortcut, security tags, scrollbar, history, suggestions, input, Chat Hidden/Commands Only and restricted mode. Toggle off to restore original backgrounds.
5. Repeat with Fabric alone, Sodium, then Iris. Capture exact versions and latest.log for failures.

Remaining primary Stray features: Skybox, Motion Blur, Picture in Picture, CS2 Knife and Held Item. Source-style parity gaps above remain tracked separately. 21 archive feature objects remain unimplemented; AetherOSSettings remains explicitly excluded.
