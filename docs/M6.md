# M6 — world visuals, Minecraft 26.2 / 0.7.0-dev

## Implemented adaptations

- **Player Glow** (`render.player_glow`): native Minecraft silhouette outline, opaque configurable color, range 16–256, visible-only or through-walls. Only alive, non-spectator, non-invisible players; local player excluded. Native/server glow remains enabled and keeps its original color. Source custom blur/post-process styles are not ported.
- **Nametags** (`render.nametags`): player-only projected labels, health/distance, scale/background/colors, range 16–256, optional third-person self. Default UUID-v4 filter skips most Hypixel NPCs; disable for offline-mode players. Discrete/sneaking players retain the 32-block limit when through-walls is off. One cached visual raycast/player/tick. F1 hides labels; a per-extraction state flag suppresses only the replaced vanilla names and is reset on every pooled-state extraction. No source remote badges, mob labels, developer cosmetics or nick-hiding system.
- **Block Outline** (`render.block_outline`): selected block's voxel-shape edges, line width 1–5, optional translucent fill and depth bypass. Shapes cap at 1024 edges/128 boxes. Native selection outline is suppressed only while the replacement has a nonempty shape. This is a contour/fill adaptation: **the Stray glow blur is not implemented**. The old OutlineBufferSource API used upstream is absent in 26.2.
- **Titanium ESP** (`mining.titanium`): loaded-only polished-diorite detection in recognized SkyBlock mining areas. Commission parsing supports inline/multiline progress, percent, ratio, Done/Complete/checkmark. All mode skips commission/region restrictions, not the mining-area guard. Regional mode uses 320 source location nodes with a 32-block nearest-node bound and null-region blockers; this is an approximation, not authoritative zone boundaries. Unknown commissions/regions fail closed. Range 16–96, nearest 1–256 highlights, fill/labels/tracers/depth options.

All four masters default off. Every settings panel stays embedded, undimmed and instant-save; numeric controls are sliders and colors use the shared palette. No new HUD-editor layout entry is needed for world-attached labels.

## Safety / performance bounds

Scanner: at most 32768 block-cell visits and 64 section jobs/tick; palette skips non-diorite sections. No forced chunk loads, network requests, mining or click automation. Cache capped at 4096 candidates. Unloaded, changed, out-of-range and newly disallowed candidates are removed before publishing. Queue replans on player section/config-filter changes, rechecks after 12 idle ticks, resets on disconnect/world change/disable/context loss. Long-distance scans may take multiple ticks to converge.

WorldOverlay now stores immutable snapshots by owner: dungeon and titanium clear only their own channels. Block selection geometry is collected for the current render frame, not cached in dungeon tick output. Existing dungeon geometry defaults to the dungeon owner.

## Manual acceptance still required

No game launch, Mixin application or Sodium/Iris/GPU test was performed here. Build, pure tests and static descriptor checks do not establish render acceptance.

1. Enable one feature at a time. Check no-player/no-target situations and F1. Vanilla/server glowing color must survive with the custom module on/off.
2. Two players in front/behind walls: through-walls on/off, range boundaries, v4/v2 NPC UUIDs and offline-filter toggle. Check names do not double-render; restore vanilla names after disable. Third-person self setting must never show first-person self.
3. Select slabs, stairs, fences and full cubes; check actual shapes, width, fill/depth options and vanilla outline restoration. Move crosshair to sky without a crash.
4. Mining area: incomplete generic and regional titanium commissions, completed commission, no commission, All toggle. Update/erase blocks, unload chunks, teleport and change worlds. Confirm no dungeon/titanium stale overlays or cross-channel clearing.
5. Save/reopen/restart all settings; run Fabric alone, then Sodium, then Iris if available. Record exact client/mod versions and latest.log for rendering faults.
