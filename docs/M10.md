# M10 — v1.0.0 milestone: accumulation blur and archive HUDs

**Version 1.0.0 is the requested release name, not a promise of complete source parity, stable in-game behavior or completion of the original backlog.** There are 40 modules, 40 mixin classes and 19 HUD editor entries. Existing masters/settings are preserved; the three new masters default off.

## Motion Blur — accumulation subset

Pinned Stray CC0 source commit `d91fcd4515b4eda647ee8fd7fa99408f473e5718`. Exact source URLs/hashes are in `audit/v1-source-manifest.json`; CC0 dedication and solyanka GPL integration notices remain bundled.

Implemented algorithms:
- Accumulation Mix: square current/previous color, mix with the previous weight, then square-root. This is the source's approximate gamma-aware blend, not physically accurate HDR linearization.
- Accumulation Max: max(current, previous × previousWeight), retaining fading highlights.
- Previous weight is the source `1 - pow(.5, strength × multiplier / 3)`, multiplier 5 for Mix and 7 for Max. Strength range 0–2; zero bypasses/releases history. These are temporal trails, not per-object/camera velocity reconstruction. Ghosting is inherent.

Native 26.2 integration:
- GameRenderer.renderLevel RETURN hook applies after world/first-person item rendering, before GUI rendering. Later vanilla entity-outline/post-effect work can remain unblurred or change the result. Uses the owning GameRenderer.mainRenderTarget, not a guessed global framebuffer.
- First processed frame copies the native frame into history without applying blur. Two depthless TextureTargets ping-pong: shader reads main + previous, writes a distinct output target, then copies output to main and swaps. Never samples the current render attachment.
- History format matches the input. Supported RGBA8_UNORM and RGBA16_FLOAT only. Native bind-group samplers, 16-byte uniform block, empty-vertex fullscreen triangle and verified draw(vertexCount, instanceCount, firstVertex, firstInstance) ordering.
- Parameters/upload/allocation happen before a pass; native pass.use closes it. No framebuffer depth copies, private PostChain/PostPass accessors, global shader injection or 24-history/depth target pool.
- Recreate/reseed on resize/format/mode/world reset and re-enable. Gaps above 500 ms reseed instead of blending stale frames. Pause in Menus defaults on and releases history; disabling that option still runs before GUI so HUD/menu pixels are not stored.
- Disable/reset/resize/GameRenderer close/shutdown release owned targets and parameter buffers. Off-render-thread cleanup is deferred to a render-thread client tick. Pipeline metadata cache is bounded to two modes × two supported formats and stays native shader-manager-owned.
- Exceptions log once and stop this module's processing until toggled; native frames are not intentionally cancelled. A driver/copy failure is not guaranteed recoverable by the exception guard.

Budget: maximum 8,388,608 pixels. 3840×2160 fits; two RGBA8 targets use 66,355,200 bytes (~63.3 MiB); RGBA16_FLOAT uses ~126.6 MiB, excluding overhead. Unsupported dimensions/formats bypass and release history. Previously enabled Skybox texture memory is additional.

**Unported source algorithms:** velocity reprojection, pre-entity/F5 velocity passes, refresh-rate scaling, weighted multi-frame blending and hybrid blending. The GUI offers only the two working code paths. No native shader-pack/GPU compatibility result is assumed; Iris/custom world targets may bypass or overwrite this effect. Native resource reload/resize behavior and performance need manual acceptance.

## Archive Stopwatch — impl/general/Timer.kt

The supplied archive hash matches the original source-lock. TimerClock logic is adapted to StopwatchClock with the same IDLE → RUNNING → STOPPED → IDLE cycle, monotonic nanoseconds, nonnegative elapsed and hour/minute/second/millisecond format. A zero-duration stop reports 0 rather than being treated as no action.

`custom.stopwatch`:
- Key/mouse bind starts, stops/reports locally, then resets; repeats do not advance state. Press/release ownership uses the existing input router.
- Requires a focused connected world, player and no open Screen. Timer key input is independent of the Command Keybinds master and takes precedence over command binds after waypoint-editor input. Choose an unused key to avoid conflicts. Escape cancels capture; Backspace/Unbind clears it.
- Stop report uses LocalPlayer.sendSystemMessage, a local feedback path. No server chat or command is sent.
- Native rounded two-line HUD, state label, elapsed text and tint. HUD visibility is independent from timing. x/y/scale/color use existing instant-save controls and the same stored layout as the new `/solyanka gui` Stopwatch entry.
- Editor sample does not start/reset the live timer or enable its master. Disable/world change/disconnect reset the clock (world reset is an added safety policy).

## Archive DVD Bounce — impl/visual/DvdBounce.kt

`custom.dvd_bounce` preserves the source's starting position, horizontal/vertical rates, frame delta clamp (.05 s), six wall-bounce colors, frame-based simultaneous-axis corner counter, optional note sound and 420 ms flash. A simultaneous collision within one render step is not a mathematical exact-corner detector.

Text (blank falls back to DVD), width 48–240, height 24–120, radius 0–40, speed 20–320, counter/sound/flash toggles. Local default text is SOLYANKA. Native font and rounded-panel approximation replace the archive's custom font/glass renderer. Text is fit to the box, counter is clamped to the screen. Tiny/zero travel axes do not create fake bounces or corner-sound spam. Flash uses monotonic time; sound is queued at most once for the next client tick rather than emitted from HUD extraction. Disable/world reset removes pending sound/state.

Motion pauses in blocking menus/HUD editor/F1; existing NoFrills-style settings/chat can show the overlay. Long pauses do not produce unbounded movement. DVD is self-moving, not a fixed HUD editor entry; total editor entries increase only for Stopwatch.

## Preserved user requirements and remaining scope

- Embedded, undimmed, instant-save settings; no Save & Back, success-status caption or 15-second preview. Palettes, sliders and LMB-next/RMB-previous choices remain.
- `/solyanka` settings, `/solyanka gui` HUD editor. Player Display's XP level/bar hiding remains independent.
- Existing `.gitignore` preserved. AetherOSSettings is excluded, not pending.
- Picture in Picture, CS2 Knife, additional blur algorithms and 19 archive feature objects remain unported. Existing adaptations keep their documented parity gaps. No all-features-complete claim.

## Validation and manual checklist

`validation/summary.json` records actual build/test counts; `check-v1-hooks.py` checks native method descriptors, owning-target shadow/compiled callbacks, native draw order, world-before-GUI call order, input ownership and archive hashes. Unit tests cover config migration/type/range validation, blur factors/budget, stopwatch states/format/zero stop/binding/HUD isolation, DVD motion/corners/resize/pause/negative time and lifecycle source guards. These are not applied Mixins or in-game acceptance.

`check-accumulation-shaders.py` translates GLSL 330 to ES 300 with precision declarations, compiles/links both fragments with the native fullscreen vertex source and compares 24 one-pixel outputs against the source formulas using Chromium SwiftShader. This is **software validation of translated shaders**, not Minecraft bind-group/native driver/visual/performance verification. Reports explicitly mark native pipeline and actual GPU testing false.

Manual checks:
1. Replace the previous JAR, keep required dependencies/config backup, start with all new masters off.
2. Motion Blur: test both algorithms at strength 0/.5/1/2; turn camera, walk, switch F5, hold enchanted items, teleport, pause/open/close menus, resize/fullscreen, F3+T, change world and toggle repeatedly. HUD/text should stay crisp; no first-frame or old-world flash. Check memory and logs.
3. Stopwatch: bind unused keyboard key and mouse button; start/hold/release/stop/reset, including near-zero stop. No actions in chat/container/settings/unfocused window. Confirm report is local; disable Command Keybinds and repeat. Drag/scale/hide in HUD editor, reopen/restart to check persistence; editor must not affect clock state.
4. DVD: test sizes/speeds/radius/text/blank, wall and simultaneous-axis bounces, counter/audio/flash switches, tiny window, F1/menu pause, resize and world changes. Disable immediately after a corner: no queued sound should play.
5. Repeat rendering tests on native Fabric, Sodium and Iris with shader packs on/off. Record versions/effect/config/latest.log. No compatibility guarantee before this acceptance.
