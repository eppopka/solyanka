# M9 — Skybox — 0.10.0-dev

## Source and included assets

Stray CC0 commit `d91fcd4515b4eda647ee8fd7fa99408f473e5718`: WorldTint (sky-only subset), SkyRendererMixin, EndSkyDecor, StrayConfig and fourteen PNGs. `audit/stray-skybox-source-manifest.json` records exact paths, URLs and SHA-256 values. The upstream LICENSE bytes match `licenses/Stray-CC0.txt`. Sky PNGs are bundled unchanged, not generated replacements. Solyanka code integration remains GPL-3.0-only. No new network requests at runtime.

## Implemented

`render.skybox` is a real registered render module, off by default. `/solyanka` → Skybox opens the same embedded settings panel.

- **Decorated End:** six source 1024×1024 cube-face textures and one black-hole patch using eight source 1536×1536 animation frames.
- **Vanilla End:** force the native End sky without decorative assets.
- **Dimension Default:** leave the dimension's native sky type; optional sky tint still applies.
- Optional RGB sky tint, source default #1B4F8A and strength .70. Color palette alpha is ignored. Intensity slider is bounded 0–1. Tint applies to sky/sunrise state, native End transform and decorative sky color modulation; it is not world/terrain lighting.
- Independent rotation and black-hole animation speeds, 0–4. Zero fixes the starting orientation/frame, not the current animation phase. Source rate at 1× is .0009 radians/game tick rotation and one animation step every 5 game ticks, ping-pong over frames 0–7.
- LMB advances/RMB reverses style choices. Bounded sliders, same palette, atomic instant-save, no second Screen, darkening, Save button or preview timer.
- Skyless dimensions remain unchanged unless explicitly enabled. No client/server dimension data is modified. No native fluid, blindness, darkness or other external sky-entry guard is cancelled.

## Native 26.2 port

- RETURN injection into SkyRenderer.extractRenderState selects the displayed sky type and adjusts color. Animation time is captured from that extraction's level/partial tick, not obtained from a live world lookup during drawing.
- Native renderEndSky now calls DynamicUniforms.writeTransform(Matrix4f). A WrapOperation uses the color-aware overload only when tint is active; otherwise it calls the original operation. There is no global uniform/pass interception.
- Decoration runs after native End sky rendering. It uses the **owning SkyRenderer.renderTarget**, not Minecraft's global main target, so the port follows native target ownership. This is not proof of arbitrary external target/shader-pack compatibility.
- Pipelines declare native bind-group layouts for DynamicTransforms, Projection and Sampler0. POSITION_TEX_COLOR at binding 0; QUADS topology; no culling; always-pass depth test with depth writes disabled.
- Six cube faces + one inverse-tilted patch: 28 vertices, 42 indices, radius 100, tilt .42, source hole direction/cone. The source premultiplied pass plus additive second frame preserves exact linear cross-fade instead of brightening it with two alpha-over draws.
- Native 26.2 draw order is indexCount, instanceCount, firstIndex, baseVertex, baseInstance. Calls use drawIndexed(6, 1, faceIndex×6, 0, 0), not the source's obsolete four-argument order.
- A private model-view matrix copy is rotated; the global matrix stack is not changed. Geometry/index growth, texture lookup/uploads and dynamic uniforms are resolved **before** opening the pass. Native RenderPass.use closes it on exceptions.
- Texture views are resolved fresh, not retained across resource reloads. One reusable vertex buffer, two pipeline definitions, at most fourteen feature texture IDs. Geometry and owned texture registrations are released on disable, world/disconnect reset, sky renderer close and shutdown. Off-render-thread cleanup is deferred to a render-thread client tick. No whole TextureManager/global pipeline/index buffer is closed.
- Draw exceptions log once and leave the previously rendered native End sky as fallback. Toggle retries. Missing-texture/resource-pack and driver failure behavior still needs in-game acceptance.

## Memory and parity limits

The raw RGBA8 total is 100,663,296 bytes (**96 MiB**) if all fourteen textures are resident, excluding driver overhead/mips. Assets load lazily as frames are visited. PNG assets total 11,215,847 bytes. Vanilla End and Dimension Default do not load these decorative textures on a fresh enable. Switching styles while enabled may retain previously loaded decorative textures until disable/reset/close; this is bounded, not a per-frame leak.

This batch does not port WorldTint's terrain/Sodium shader/lightmap color path or its match-sky-to-world link. Sky tint is independent. It intentionally preserves zero sunrise alpha rather than turning an absent sunrise band opaque, and gates naturally skyless dimensions behind an explicit option. Tinting the decoration and independent speed controls are solyanka extensions.

Shader packs that replace or skip vanilla sky rendering may hide or override this module. No Iris shader-source injection, GPU acceptance, visual seam/performance result or Sodium/Iris compatibility is claimed. No all-features-complete claim: Motion Blur, Picture in Picture, CS2 Knife and 21 archive feature objects remain unported; existing adapted modules still have documented parity gaps. AetherOSSettings is excluded.

## Validation and manual acceptance

Current clean-build, JUnit and static results are in validation/summary.json. Skybox tests cover strict config/default migration, mode/master/skyless gates, tint alpha/endpoints, ping-pong boundaries/large/negative time, zero speed, source cube/patch geometry, all texture dimensions and renderer guards. `check-skybox-hooks.py` verifies exact native descriptors, single transform callsite, native draw parameter names/order, compiled shadow/wrap annotations/signature and all imported texture hashes in the built JAR. Static checks do not establish Mixin application.

Manual checklist:
1. Remove older solyanka JARs. Launch Fabric 26.2 with Skybox off; ensure no sky changes.
2. Enable Decorated End in the Overworld; inspect all six directions and the black hole. Check seams, orientation and linear animation turnarounds. Revisit at different times/weather.
3. Switch to Vanilla End and Dimension Default; verify decoration disappears and the native sky/time/weather behavior returns. Toggle tint; test strength 0/1, colors and sunrise transparency.
4. Test each speed at 0, 1 and 4. Reopen settings/restart: all choices must persist without Save. Test reverse mode cycling with RMB.
5. In a skyless dimension, confirm default exclusion, then explicit opt-in. Check water/lava, blindness/darkness and cloud/fog interplay; the mod must not bypass native sky-entry guards.
6. F3+T/resource packs, disconnect/rejoin, dimension change, repeated enable/disable, window resize/fullscreen: inspect logs, native fallback and texture/buffer memory behavior.
7. Repeat with Sodium, then Iris shaders disabled/enabled. If a pack replaces the native sky, record that limitation; report crashes with latest.log, pack/mod versions and selected settings. No compatibility result is assumed.
