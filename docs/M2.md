## Intentional 26.2 adaptations / differences

- `Hud.getChat()` owns chat; the disconnect operation is on `Hud.onDisconnected`, not the old Gui method.
- Full copy uses `GuiMessage.Line.parent().content()`. It captures the logical original message, including off-screen wrapped parts and original spaces/newlines, rather than concatenating only upstream's visible glyph lines. Wrapped-line copy uses visible formatted glyph content; bidirectional text may therefore differ between full and line copy.
- Hover coordinates follow 26.2's scaled/floored baseline and horizontal offset. Scroll, chat width, scale, spacing and visible line count are respected. They still require visual in-game validation.
- Extra Lines changes both 100-message/100-display-line caps, not the sent command-history deque. Enabling/lowering a limit does not retroactively trim until subsequent insertion. Existing retained lines are not restored if previously discarded.
- Keep History suppresses only disconnect clearing, not every `clearMessages` call. Manual F3+D works. Received chat can be visible after joining another server/world until manually cleared; it is not written to a new disk archive.
- Tooltip additions use Fabric ItemTooltipCallback and only stacks with CUSTOM_DATA, matching the upstream guard. No price lines are implemented here.
- Data errors are contained. Malformed pet JSON produces UNKNOWN_PET instead of crashing tooltips. Missing source data omits a line.
- Settings are staged and validated rather than auto-written after each control change. Existing command profiles, unknown nested JSON and other module settings are preserved.

## Museum provider / privacy / failure behavior

The original `https://whatyouth.ing/api/nofrills/v1/items/get-museum-data/` returned HTTP 401 without NoFrills headers and 403 with an honestly identified solyanka version during development. No authentication bypass or credential request was attempted.

Instead this port uses Hypixel's public, keyless `https://api.hypixel.net/v2/resources/skyblock/items`. Parse `museum_data.category` and `mapped_item_ids`; normalize STARRED_ for the upstream base-item lookup. A checked response had 1060 museum items and yielded **1081 category IDs** including mapped variants. This is not a claim of exact category parity with NoFrills' inaccessible private response. The public resource may change later.

Requests start only with Info Tooltips enabled, Museum enabled, and a world/player present. Initial request is immediate; subsequent attempts no more than every ten minutes, including failures. One request in flight. Connect timeout 8 seconds, request timeout 12 seconds, future wait bound 15 seconds; redirects disabled. A streaming subscriber caps the body at 8 MiB even without Content-Length. Parsing occurs on a virtual background thread. Only an immutable category map is published; no Minecraft objects are accessed from the worker. The Java HTTP client is closed and its pending operation cancelled on timeout.

No player names/UUIDs, inventory, target server addresses or credentials are sent. The endpoint sees the connection IP and a solyanka User-Agent. The entire public item resource is downloaded to derive categories, not queried per item. No disk cache. Disabling prevents new requests; an already-started request may complete and update session cache. Failed requests log at most once per interval and retain last-good data; missing categories are silently omitted. Reloading the game resets cache/attempt state.

## Persistence / threads / test boundary

`generalUtilities.chat` and `.tooltips` extend schema 1. Strict typed decode and candidate validation protect against invalid writes. Unknown fields survive recursive merges, including copy-binding subobjects. Save profile/toggles/general settings in the same atomic transaction; runtime applies afterward.

All input, configuration, module and GUI work stays on the client thread. Museum I/O/parsing is isolated in its own background worker and publishes a volatile, no-longer-mutated map. It is account-independent public data and intentionally survives world changes within the process.

**96 tests pass**: 60 prior tests + 32 new domain/network tests + 4 config migration/failure tests. New static mixin checks and a compiled parser check against the live resource are included. No Minecraft launch or new runtime acceptance was performed here. Price Tooltips, broader SkyBlock context and every other requested feature remain on the roadmap; this is M2a, not completion of the whole mod.
