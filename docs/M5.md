# 0.6.0 — XP-only hiding and Stray HUD adapters

## Source and scope
Pinned Stray revision: `d91fcd4515b4eda647ee8fd7fa99408f473e5718`, CC0; source file paths and adaptations in NOTICE. Three new real modules: `hud.inventory`, `hud.item_name`, `hud.skill_progress`. All master switches default off. AetherOSSettings is excluded, not deferred. Scope is recorded in audit/scope.json; the original archive inventory is not deleted.

## XP visibility
`hideXp` still controls only the level number. New `hideXpBar` defaults false and is independent. It applies only while Player Display is enabled and SkyBlock context is recognized. The mixin targets ExperienceBar.extractBackground/extractRenderState, not the shared Fabric INFO_BAR, so mount jump/locator bar code is not suppressed. Vanilla gameplay, XP values and packets are untouched. Existing configs migrate without changing old flags.

## Inventory
Source slot grid and layout metrics are adapted: 27 main slots (9–35), optional nine hotbar slots (0–8), four equipped armor slots plus offhand, /41 occupancy count, vanilla item decorations, selected-hotbar outline. Minimal mode removes heading/slot outlines. Panel color is configurable; no GPU blur, custom font or separate Stray theme runtime. No interaction, inventory manipulation or network request.

## Item Name
Persistent styled main-hand hover name, no display for empty hand; panel and text color plus optional vanilla fading-name suppression. No stack-reference name cache, so changed names/NBT update with the current stack. This implements Item Name HUD, not the separate Held Item shader or knife cosmetic feature. Original component styles are preserved when supported by vanilla drawing.

## Skill Progress
Original action-bar formats, twelve source skill families, alias, XP tables and level hints are adapted. Ratios retain observed XP/denominator; percentages use observed/table-denominator evidence when available, otherwise display percentage only. Level recognition reads at most 80 tab entries and at most 512 non-player container slots in recognized Skills menus every 10 ticks. Container lore is bounded. The action bar is observed before Player Display strips fields. Unsupported/custom skills stay unavailable, never fake sample values.

Malformed/negative/out-of-range progress does not replace the last-good snapshot. Optional timeout is monotonic; zero keeps latest until reset. World change, disconnect, leaving SkyBlock and module disable clear observations. Session state is not persisted between servers and no remote skill/profile lookup occurs. Tables are source-derived, not guaranteed future-server caps. Custom-font/blur parity and Stray item-appearance suppression aren't included.

## UI/editor
Same-Screen settings, instant atomic saving, sliders/palettes remain. `/solyanka gui` has 17 selectable entries. Inventory bounds use actual configured metrics; Item Name and Skill Progress use representative text/icon dimensions. New HUDs render representative editor-only samples without enabling master modules. Runtime text can change width; renderers clamp live placement to current screen bounds. Flat panel background is independent of the transparent full-screen root.

Enable each new HUD; check inventory counts, durability, selected hotbar, empty held item, real skill XP action bar (ratio/percent/MAXED), menu/tab level hints, expiry, reconnect reset, dragging/scaling/toggling and restart persistence. Compile/unit/static checks do not constitute in-game/GPU acceptance.
