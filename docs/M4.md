## Provenance

- Odin `19118e15bfb57a953c3264373a32b42171c5f281`, source target 26.3, BSD-3-Clause (odtheking 2025).
- NoFrills `74e9317c1a7b8484a575b2f177479f5e3f2bfb9a`, source target 26.1, GPLv3.

### Odin source trace

`WorldScan.kt`, `map/tile/DungeonRoom.kt`, `RoomData.kt`, `MapScan.kt`, `DoorHighlight.kt`, `MapInfo.kt`, `Mimic.kt`, `dungeonwaypoints/{DungeonWaypoints,DungeonWaypointEditor,DungeonWaypointPacks,SecretWaypoints}.kt`, `config/{DungeonWaypointConfig,WaypointPackFileUtils}.kt`, `EventDispatcher.kt`, `DungeonListener.kt`, `DungeonUtils.kt`, `VecUtils.kt`, `RenderUtils.kt`, and `puzzlesolvers/{IceFillSolver,BlazeSolver,BeamsSolver}.kt` inform the new ports.

`rooms.json` (140 definitions), `puzzles/ice-fill-floors.json` and `puzzles/creeper-beams-solutions.json` are byte-identical source resources. Tests pin their hashes and route/coordinate structure.

#### Room and rendering differences

- Scan only loaded columns at fixed dungeon tile centers; never request/load chunks. Cache recognized cores; retry unknown columns. Scan cadence up to once per second, at most 36 columns ×129 blocks per pass. Current room needs source below-roof predicate.
- 1x1 rooms use source blue-terracotta rotation probes; Fairy uses source fallback. Multi-tile room geometry waits for all segments of the same definition. Straight/square shapes are validated; L uses deterministic missing-corner normalization to avoid upstream iteration-order ambiguity. No full minimap/teammate/checkmark rendering is advertised.
- Solvers and world geometry refresh every five client ticks. Ice routes require all floor identifiers; no partial path is emitted. Blaze priority is derived from displayed max HP; malformed tags are ignored. Display boxes/lines use solyanka's 26.2 LevelRenderEvents COLLECT_SUBMITS pipeline, camera-relative matrices and immutable snapshots.
- Shared world outlines/fills/text are separate from upstream RenderUtils. F1 hides them. Depth-disabled pipelines disable depth writes and use ALWAYS_PASS; fills use translucent, non-writing depth. World text/alpha/occlusion are not GPU-tested here.
- The access widener uses the **official** namespace and exposes only RenderPipelines LINES/DEBUG_FILLED snippets + register and RenderType.create. The AW validator and static member checks must pass.

#### Waypoint scope

- Odin JSON, legacy coordinate/AABB aliases, color #RRGGBBAA and optional legacy secret flag; Base64+GZIP input/output. New solyanka file layout: config/solyanka-waypoints/<name>.json. No automatic migration from Odin directories and no bundled route pack.
- Clipboard only; no remote URL fetch. Limits: 8MiB input/expanded payload, 512 rooms, 2,000 waypoints/room, 20,000 total, finite bounded positions/boxes and 128-character single-line titles. Invalid packs reject as a whole. Pack names cannot contain path separators/dots. Existing corrupt/unreadable/symlink files are not overwritten.
- Atomic file edits, read-before-overwrite, no success claim after failed writes. Pack content saves immediately on manual add/remove. File operations are local/client-thread and bounded; very large packs may cause a UI pause. No automatic background file watcher. Runtime collected state is per pack/room instance and resets on world change.
- Manual world right-click editor only while Allow Edits is on, within vanilla targeted block reach. Optional titles through command; embedded per-room deletion controls. No separate title Screen, no Save. Custom dimensions/block shapes, colors, depth and filled/outline supported; upstream presets/key-cycle/editor HUD/rainbow picker are not ported.
- Secret interactions match chests/trapped chests/levers or source essence/redstone skull UUIDs. Source item-drop name list, nearby pickup/removal and 0.1-volume bat hurt/death sound events hide the nearest Secret within source squared thresholds (3/5); no generic mob-drop matching. This remains event-based, not server-confirmed secret accounting.
- Etherwarp hiding observes a manual crouch/AOTE/AOTV right click and a corresponding server player-position packet within 1s/3 blocks. Uses vanilla bounded raycast (56+tuning capped at10) instead of upstream full target validation; not automatic movement. Collection reset does not mutate disk pack data.

#### Door / Map / Mimic scope

- Door parsing needs the named Magical Map item and its 128² saved color data; recognizes source 16/18-pixel entrance layout and wither/blood colors. Source chat key counters/openable colors and key entity alerts. Loaded-air door centers suppress stale highlights. No raw world-block guessing for unknown maps; no map => no door highlight.
- Map score is labeled approximate; missing total-secret/room/death/crypt/puzzle inputs suppress the 300 alert and portal estimate. Formula includes source floor secret fractions, room exploration/skill, puzzles/deaths, crypt/mimic/prince/bat/Paul bonuses; time score remains source's +100 assumption. Paul is explicit manual setting, not fetched. Mimic must be enabled to detect its entity-death bonus. Party-reported mimic reconciliation, upstream time/bonus network providers, full discovered/unknown-secret aggregation and original HUD layout/selectors are not implemented.
- Room-secret action-bar values skip the first sample after a room transition. A recognized Blood room rotation is required for portal bounds. Score alert is local chat/action-bar, not party chat. No guaranteed S+ claim.
- Mimic is a baby-zombie F6/F7 clear death heuristic and visual candidate outline, not authoritative identification. Prince exact line is deduplicated; bat source bonus lines count. Optional announcements are party commands and off by default; local feedback remains. Repeated/unseen/deferred server events may affect estimates.

### NoFrills source trace and differences

`features/general/{NoRender,PriceTooltips}.java`, `features/solvers/ExperimentSolver.java`, `misc/{NoFrillsAPI,Utils}.java` plus relevant client packet, container, HUD/effects/recipe, entity extractor, fog, game renderer and screen effect mixins inform the adapters.

- ExperimentSolver retains Chronomatron reveal/clock ordering, Ultrasequencer visible-dye order and Superpairs reward equality (item/name/count/texture) and powerups. Real stack copies are redrawn only for presentation; menu inventory/server contents are not spoofed. Bulk and per-slot snapshots are handled after vanilla on its game thread. GUI identity, close/world/disable clear memory. Only player-directed clicks; optional wrong-slot cancellation, no auto-clicks.
- No Render implements all 30 source settings in independent filters (see SuppressionSettings). Status/liquid fog remains. Cocoon filtering uses visible nearby Tarantula Broodfather name presence instead of the source full slayer tracker, so it is a heuristic. Entity/name/fire, XP/arrows, exact packet particle patterns, GUI layers/recipe/effects/tooltips, vignette and nausea hooks are source-derived. Option interactions/visual fidelity are not in-game tested. Empty tooltip suppression excludes Ultrasequencer.
- Price network master + explicit Network option required. Primary endpoint https://whatyouth.ing/api/nofrills/v2/economy/get-item-pricing/ returned401. Public fallbacks: Hypixel /v2/skyblock/bazaar, /v2/resources/skyblock/items and https://moulberry.codes/lowestbin.json (returned525 during audit). Failed provider data is not fabricated. Combined schema retains motes when supplied; no mote fallback exists.
- Requests are background virtual-thread tasks: connect8s/request15s/wait18s, <=12MiB per response, no redirects, 5-minute refresh/retry. Remote servers see IP/User-Agent only; no account, inventory, server address or API key is sent. In-flight public-data work may finish after disable/disconnect. Public price snapshots survive worlds; no price history database.
- No prices loaded => explicit unavailable/opt-in status. A failed refresh keeps last-good data and marks it stale; timestamps/status are rendered. Hypixel fallback quotes are quick-status weighted summaries, not guaranteed immediately executable prices; bid/ask directions are translated to player-facing Buy/Sell labels. Quantity honors source stored/compost/syphon/owned lore or item count; malformed lore falls back safely. Craft costs reject unknown ingredient prices and cycles; not every recipe is known.
- Confirm Purchase click records local UUID/cost; not transaction acknowledgement and can differ if a purchase fails/cancels. Craft recipes are captured only from final-slot/bulk fully updated six-row Crafting Table menus, not arbitrary intermediate snapshots. Persist known recipes/paid costs in config/solyanka-market.json (<=8MiB load cap), atomic replacement; corrupt files disable writes. Public prices themselves are not persisted.

### Stray source trace and differences

`visual/{CustomAmbience,CustomFog}.java`, `render/AspectFov.java`, `mixin/{ClientClockManager,Level,WeatherEffectRenderer,Projection,Camera,FogRenderer}Mixin.java` (CC0).

- Clock presets are source constants but only affect the client Overworld clock holder, not every clock/integrated-server state. Weather overrides guard client-side Level. Snow adapts the renamed 26.2 ClientLevel.getPrecipitationAt call during weather extraction; intensity adapts the two weather render state reads. No precipitation physics.
- Aspect multiplies both projection width and culling matrix aspect; shader/other camera mod conflicts remain acceptance work. PiP/top-down capture exclusions will be needed if those modules are added later.
- Fog reuses the shared atmospheric-environment selection so status/liquid fog is never overwritten; No Render suppression wins. Color, start/end, density and vanilla-density curve retain source math. Sodium loaded => native distances/color alpha, **without** source shader injection/uniform patch. This is not exact high-density Sodium parity; Iris behavior is unverified.
- No Stray skybox, motion blur, ESP/glow, HUD, PiP, knife/held shader or its assets are included in this batch. No placeholder exists for these pending items.

### Archive

MimicChest.kt: trapped block-entity scan from loaded chunks, 20-client-tick scan, 5-tick visual snapshot, filled depth-tested shape, configurable ARGB. Supports boss/clear dungeon context but still requires shared dungeon detection. Rendering may lag chest removal by <=5 client ticks; source draws validation every frame. No other archive feature is called complete; its OdinDungeonWaypoints adds route-step/HUD logic beyond the new Odin-compatible pack module and remains pending.

## Validation

Pure tests + clean compile/build + AW validation + exact target/member/operation/thread-guard checks. See validation/summary.json for counts. No in-game, GPU, Mixin-transform launch or performance-mod acceptance. Server rules remain the user's responsibility; all modules/network/party sends are explicitly opt-in.
