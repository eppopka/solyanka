# 1.3.0 — combined integration milestone (not final full-parity release)

Target remains **Minecraft 26.2, Fabric, Kotlin, Java 25**. This release extends 1.2.0: 55 real module cards, 41 Mixin classes, 25 HUD editor entries. New masters default OFF. Existing direct `/solyanka`, transparent embedded settings, instant atomic saving, slider/palette controls, RMB reverse choices and separate XP-bar/level hiding remain. `.gitignore` is unchanged.

## Blocklist storage and external actions

`config/solyanka-shitters.json` stores JSON `{uuid,nickname,reason}` entries. `/sl importlegacy` reads `config/shitters.txt`, validates it, and merges into the new file **without modifying the legacy file**. Corrupt new files disable writes rather than silently replacing data. Back up before manual editing; restart to reload edits.

Network lookups and Auto Kick default off. Without network permission, identity must already be available in the online player list. Mojang requests contain only validated usernames. Pending server actions cancel on world/module changes; no retry loop. Review server rules before enabling automated commands.

## Explicit exclusions

Only these archive modules are excluded: **Cosmetics**, **AutoRag**, **AutoReel**, **AetherOSSettings**. The user's named Cosmetics exclusion is NOT a category-wide exclusion: ChinaHat, Halo, Item Aura and CS2 Knife stay in scope.

## Still unfinished (do not call the project complete)

- **Item Aura**: audited; no runtime toggle/backend added yet. First-person post-hand rendering needs a correct native integration, not world geometry that appears behind the hand.
- **CS2 Knife**: decoder/backend sources audited, not integrated. No Valve model/material assets bundled or downloaded. User-provided local assets will be necessary for testing the eventual port.
- Partial items in the table above.
- Earlier documented partial parity: velocity/hybrid/pre-entity/F5/weighted/refresh-scaled Motion Blur; held-item arms/silhouette/special models; skybox terrain/world tint; framebuffer glow/outline blur; nametag badges; themed-chat blur/animations; remaining Odin/NoFrills option/provider details. See prior milestone docs.

## Validation boundary

Pure Kotlin regression tests cover evidence expiry, meshes, sequence transitions, route ordering, pet parsing/rates, storage corruption and HUD transforms. Native descriptor checks verify both block update hooks execute after the packet thread guard and before world replacement. PiP privacy/lifecycle checks inspect source/compiled structure, NOT real Windows behavior. Existing shader checks are offline software GL tests, NOT Minecraft GPU acceptance.

A clean build is not proof of Mixin application, live Hypixel protocol recognition, Windows capture or Sodium/Iris compatibility. These require the user's in-game testing. This release is deliberately described as an integration milestone, not the requested all-features final update.
