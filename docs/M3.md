## Tick Timers fidelity and dependencies

All six actual HUD implementations in the pinned file are implemented: Goldor tick/start, Storm pad/lightning/PY/phase, Fire Freeze. The source module's old prose mentions other timers, but no separate Necron/outbounds/secrets HUD implementation exists in that pinned file; no invented implementation is claimed.

Exact anchored boss lines seed 60/64/20/520/55/206 tick state. Nonzero common ping packets advance state once each; id zero ignored. The vanilla handler's main-thread guard precedes our TAIL callback. We never cancel pings or pongs. This deliberately avoids Odin's original Netty-thread state mutation. No client-tick approximation, wall-clock extrapolation or fallback is substituted: no valid ping means no countdown progress.

Only recognized SkyBlock dungeon floor and boss coordinates allow advancing/displaying real timers. Unknown floor fails closed. Coordinates follow Odin floor groups F/M1, 2–4, 5–6, 7. Sidebar floor text is `The Catacombs (F1..F7/M1..M7)`; tab Catacombs labels supplement dungeon identification, but do not guess a missing floor. World changes/disable reset timers and PY one-shot. Leaving dungeon/changing floor clears stale state.

Formatting preserves ticks vs two-decimal seconds, suffixes, prefix toggles and green/orange/red thresholds. Goldor/pad loops depend on HUD enabled state, as in the source. Fire Freeze counts to 106 ticks before its 100-tick prompt window. No fire-freeze ability or puzzle input is automated.

## Player Display fidelity and differences

Seven stat HUDs, all source visibility/overflow/icon toggles, and independent enable/position/scale/RGB settings are exposed. Input is parsed before selected action-bar portions are stripped. Health is refreshed from max SkyBlock HP times vanilla health ratio; speed from base MOVEMENT_SPEED × 1000. EHP retains Odin's integer defense quotient, but uses Long to avoid Int overflow and recomputes from current health. Vitality is visible only if the current action-bar update contains it. PUA glyphs and legacy heart/mana/overflow/defense/vitality symbols are accepted; malformed/overflowing numbers are ignored.

Only a SKYBLOCK sidebar enables live stat HUDs/hiding. World changes/disable clear state. Fabric armor/health/food/XP-level layers delegate to their original elements unless explicitly hidden, rather than broad HUD cancellation. XP bar remains unchanged. Changed action-bar text is rebuilt as literal text like Odin; its remaining rich styles can be lost. Unchanged messages retain their Component/styles.

HUDs default enabled within disabled master modules, with non-overlapping initial coordinates. Odin's generic toggleable HUD helper initially disables them at overlapping coordinates; this default is intentionally changed for usability. Positioning is numeric GUI-scaled pixels and clamps at render time, not a copied drag editor. Player colors are opaque RGB; alpha/rainbow/Compose picker widgets are not ported. Timer state colors are fixed source thresholds, not arbitrary per-HUD colors.

Preview controls and `/solyanka preview timers|player` render local sample data for 15 seconds only when the corresponding master module/HUD is enabled. They do not seed real timer/stat state, send network commands, or claim a boss event occurred. World reset cancels previews. Normal F1 HUD hiding applies; non-game/menu screens other than solyanka/chat suppress the custom HUD.

## NoFrills utilities: boundaries

- **Animation Fix:** only the first POSE-serialized metadata value for the local entity is excluded; remaining entries and all other entities are passed through. The input packet list is not mutated. Optional SkyBlock-only guard. This does not grant movement abilities or send replacement packets.
- **Middle Click Fix:** changes only the creative-material check in container mouseClicked, allowing the configured pick-item click to use vanilla CLONE in survival. No creative inventory grant.
- **Middle Click Override:** wraps only ordinal 1 of slotClicked inside mouseClicked (the manual, empty-carried-item branch). Converts eligible left PICKUP to button 2 / CLONE, clears doubleclick, preserves one original operation call. All 25 exact blacklist titles, four exact whitelist titles, 11 fragment exclusions, Bits Shop, paginated-title handling, three transaction lore labels and Rename Loadout checks are retained. It is SkyBlock ContainerScreen-only. Shift/throw/drag/player inventory/carried-item paths remain untouched. Debug output is local. Server rules may restrict click-remapping utilities; the user must review them.
- **No Cursor Reset:** captures before vanilla recenters on grab, restores through vanilla release plus GLFW position, tracks 0–1200 GUI-closed in-world ticks. Zero retains until explicit reset. Screen transitions restart timeout, resize clamps coordinates, world/disable clears. Spirit Leap always remains centered here (upstream exclusion requires its LeapOverlay feature, which is not implemented in solyanka). No OS cursor access outside the game window.
- **No Loading Screen:** *not source-identical*. Only terrain-loading foreground/background extraction is cancelled; loading screen lifetime, ticking, readiness, input gating and packets are untouched. No initial connection/resource-pack/disconnect/error screen is bypassed. Remote-only excludes LAN/singleplayer by default. This safety adaptation can remove text/portal visuals without making a new world ready faster; black/previous frames may still be shown if vanilla has no ready world to render. No full loading-screen bypass is claimed.

## Settings, packaging and validation

Existing instant-save embedded UI is retained. `generalUtilities.features` is an additive typed section; strict known-field validation, default filling and recursive unknown-field preservation remain. Each HUD position/scale/color input validates before a write; invalid local text shows an inline error and preserves last-good data. Other valid controls can save while a malformed HUD numeric/color field stays local; raw invalid text does not reach config. Controls that affect server click behavior default off.

All 12 master modules are real registered implementations (diagnostics + 11 requested feature entries). There are no fake toggles for unresolved features. Existing dependencies stay unchanged. Odin's full BSD notice ships in binary/source distribution alongside GPL LICENSE/NOTICE. No upstream frameworks, shaders, artwork or other mod JARs are bundled.

Pure unit tests, clean compilation and static bytecode/annotation checks do not establish actual Mixin transformation, server behavior, HUD appearance, cursor handling or mod compatibility. Follow TESTING.md and supply actual dependency versions/logs for failures. No new Minecraft in-game test was performed here.
